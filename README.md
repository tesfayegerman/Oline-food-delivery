🍔Online Food Ordering System (MESKEREM HOTEL)
🍲🌮🍛🫔🍶🍺🫗🍼
This is a console-based Java application for an online food ordering system developed for MESKEREM HOTEL in Jinka.  
The system allows customers to order food and drinks, and administrators to manage the menu and view orders.

🍔 Features
- User registration and login
- Customer and Admin roles
- Browse food and drinks
- Age verification for alcoholic drinks
- Add items to cart
- View cart
- Checkout with payment option (Pay now or COD)
- Order tracking with date and estimated delivery time
- Admin menu management (Add, Update, Remove items)
- Admin view all orders

🍔 Technologies Used
- Java
- OOP Concepts (Inheritance, Abstraction)
- Java Collections (ArrayList)
- Date & Time API
- Scanner for input
